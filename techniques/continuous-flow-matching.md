# 🌊 Continuous Flow Matching & Optimal Transport: Fast Denoising for Physical AI & Vision

## 1. High-Level Concept & The Diffusion Latency Bottleneck

Denoising Diffusion Probabilistic Models (DDPMs) revolutionized generative vision and robotic trajectory synthesis by learning to reverse a stochastic forward noising process. However, standard diffusion has a fatal operational flaw in real-time edge systems:
- **Curved Brownian Paths**: Diffusion formulates trajectories via Stochastic Differential Equations (SDEs), causing generative paths to curve erratically through high-dimensional probability space.
- **Prohibitive Sampling Latency**: To avoid numerical divergence, DDPM requires $50\text{ to }1000$ sequential forward evaluation steps. Even accelerated samplers (DDIM, DPM-Solver) require $10\text{ to }20$ steps.

In real-time physical AI and robotics (e.g., controlling a 7-DoF robot arm at $50\text{ Hz}$ or autonomous vehicle emergency braking), allocating $200\text{--}500\text{ ms}$ for diffusion denoising is non-viable.

**Continuous Flow Matching (CFM)** (Lipman et al., 2023; Liu et al., Rectified Flow, 2023) replaces stochastic curved diffusion paths with **straight, deterministic vector field trajectories** governed by Ordinary Differential Equations (ODEs):
1. **Straight Trajectories**: Uses **Optimal Transport (OT)** to draw direct straight lines between random Gaussian noise $\mathbf{x}_0 \sim \mathcal{N}(0, \mathbf{I})$ and clean target data $\mathbf{x}_1 \sim p_{\text{data}}$.
2. **Deterministic ODE Integration**: Evaluates the velocity vector field with simple forward Euler or Midpoint integration, achieving high-fidelity generation in **1 to 4 steps** ($<10\text{ ms}$ latency).

```
DDPM Curved Diffusion Path vs. Optimal Transport Flow Matching:

DDPM (Curved SDE Path):              Flow Matching (Straight ODE Path):
    Noise x_0                            Noise x_0
        \                                    \
         ~~\                                  \
            \~~                                \
               \                                \
                Clean x_1                        Clean x_1
 (Requires 50-100 iterative steps)   (Requires only 1-4 Euler ODE steps!)
```

## 2. Mathematical Formulation

### 2.1 The Probability Path and Vector Field
Let $p_0 = \mathcal{N}(0, \mathbf{I})$ denote the simple base Gaussian distribution at time $t = 0$, and $p_1 = p_{\text{data}}$ denote the target data distribution at time $t = 1$.

A time-dependent probability density path $p_t(\mathbf{x})$ is generated by pushing $p_0$ forward along a time-dependent vector field $\mathbf{v}_t(\mathbf{x}): \mathbb{R}^D \times [0, 1] \to \mathbb{R}^D$ according to the **continuity equation**:

$$
\frac{\partial p_t(\mathbf{x})}{\partial t} + \nabla \cdot \left( p_t(\mathbf{x}) \mathbf{v}_t(\mathbf{x}) \right) = 0
$$

---

### 2.2 Optimal Transport Displacement Interpolant
For any pair of source noise $\mathbf{x}_0 \sim p_0$ and target data $\mathbf{x}_1 \sim p_1$, the optimal transport displacement interpolant defines a straight linear path across time $t \in [0, 1]$:

$$
\mathbf{x}_t = \psi_t(\mathbf{x}_0, \mathbf{x}_1) = (1 - t) \mathbf{x}_0 + t \mathbf{x}_1
$$

Differentiating $\mathbf{x}_t$ with respect to time $t$ yields the constant conditional velocity:

$$
\mathbf{u}_t(\mathbf{x}_t \mid \mathbf{x}_0, \mathbf{x}_1) = \frac{d\mathbf{x}_t}{dt} = \mathbf{x}_1 - \mathbf{x}_0
$$

Notice that the true velocity target is simply the straight displacement vector from the noise to the clean data point.

---

### 2.3 The Conditional Flow Matching (CFM) Objective
Training a neural network $\mathbf{v}_\theta(\mathbf{x}, t)$ directly on the marginal vector field $\mathbf{v}_t(\mathbf{x})$ is intractable because $p_t(\mathbf{x})$ is unknown.

However, the **Conditional Flow Matching Theorem** proves that regressing against the simple conditional vector field $\mathbf{u}_t$ yields the identical gradient as regressing against the true intractable marginal vector field:

$$
\mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t \sim \mathcal{U}[0, 1],\, \mathbf{x}_0 \sim p_0,\, \mathbf{x}_1 \sim p_1} \left[ \left\| \mathbf{v}_\theta(\mathbf{x}_t, t) - (\mathbf{x}_1 - \mathbf{x}_0) \right\|^2 \right]
$$

where $\mathbf{x}_t = (1 - t)\mathbf{x}_0 + t\mathbf{x}_1$. 

**Training Complexity**: Requires only drawing $t \sim \mathcal{U}[0, 1]$, interpolating $\mathbf{x}_t$, and computing an MSE loss against $(\mathbf{x}_1 - \mathbf{x}_0)$. There is zero SDE variance scheduling, zero SNR clipping, and zero complex loss weighting.

---

### 2.4 Ultra-Fast Inference via Euler ODE Integration
To generate a clean robotic action trajectory or visual sample at inference time:
1. Sample random Gaussian noise $\mathbf{x}_0 \sim \mathcal{N}(0, \mathbf{I})$.
2. Discretize the time interval $[0, 1]$ into $K$ steps with step size $\Delta t = \frac{1}{K}$ (typically $K = 2\text{ to }4$).
3. Integrate the learned velocity field $\mathbf{v}_\theta$ using the forward Euler rule:

$$
\mathbf{x}_{t + \Delta t} = \mathbf{x}_t + \Delta t \cdot \mathbf{v}_\theta(\mathbf{x}_t, t)
$$

The final state $\mathbf{x}_1$ is the clean, generated sample.

## 3. Comparison of Generative Trajectory Paradigms

| Generative Formulation | Trajectory Geometry | Minimum Inference Steps | Latency (Robot Policy) | Training Stability |
| :--- | :--- | :---: | :---: | :--- |
| **DDPM (Standard Diffusion)** | Brownian curved stochastic path | 50–100 | Prohibitive ($>200\text{ ms}$) | Sensitive to noise schedule |
| **DDIM (Accelerated Diffusion)** | Non-Markovian deterministic path | 10–20 | Marginal ($40\text{--}80\text{ ms}$) | Moderate |
| **Continuous Flow Matching (CFM)** | **Straight line displacement** | **1–4** | **Real-Time ($<10\text{ ms}$)** | **Highly stable (Pure MSE)** |

## 4. PyTorch Reference Implementation

```python
import torch
import torch.nn as nn

class ConditionalFlowMatcher(nn.Module):
    """
    Continuous Flow Matching (CFM) module with Optimal Transport straight paths.
    Supports both training loss evaluation and fast Euler ODE trajectory sampling.
    """
    def __init__(self, velocity_net: nn.Module):
        super().__init__()
        self.velocity_net = velocity_net

    def compute_loss(self, x1: torch.Tensor, condition: torch.Tensor = None) -> torch.Tensor:
        """
        Computes the Conditional Flow Matching MSE loss.
        x1: [B, D] clean target action or image features
        """
        b = x1.shape[0]
        # 1. Sample base noise x0 ~ N(0, I)
        x0 = torch.randn_like(x1)
        
        # 2. Sample uniform time t in [0, 1]
        t = torch.rand(b, 1, device=x1.device)
        
        # 3. Linear displacement interpolation: x_t = (1 - t) * x_0 + t * x_1
        xt = (1.0 - t) * x0 + t * x1
        
        # 4. Target constant velocity: u_t = x_1 - x_0
        target_velocity = x1 - x0
        
        # 5. Predict velocity field
        pred_velocity = self.velocity_net(xt, t.squeeze(-1), condition)
        
        # 6. Mean Squared Error loss
        return nn.functional.mse_loss(pred_velocity, target_velocity)

    @torch.no_grad()
    def sample(self, shape: tuple, num_steps: int = 4, condition: torch.Tensor = None, device="cpu") -> torch.Tensor:
        """
        Fast forward Euler ODE solver to generate samples in num_steps forward passes.
        """
        # 1. Start from pure Gaussian noise x(t=0)
        x = torch.randn(shape, device=device)
        dt = 1.0 / num_steps
        
        # 2. Integrate ODE forward from t=0 to t=1
        for step in range(num_steps):
            t_val = step * dt
            t = torch.full((shape[0],), t_val, device=device, dtype=torch.float32)
            v = self.velocity_net(x, t, condition)
            # Euler update
            x = x + dt * v
            
        return x
```
