# 🔬 Vitis AI 3.5 & FINN: High-Efficiency Reconfigurable Deep Learning

## 1. Executive Brief & Significance
While GPUs dominate batch-throughput training, Field-Programmable Gate Arrays (**FPGAs**) excel in mission-critical edge robotics, industrial factory automation, and aerospace where:
1. **Latency determinism** must be guaranteed with sub-millisecond jitter ($<1\mu\text{s}$).
2. Power budgets are strictly constrained ($5\text{ W} - 25\text{ W}$).
3. Hardware interfaces require direct physical digital I/O without PCIe host CPU overhead.

The two dominant open-source FPGA paradigms are:
- **AMD / Xilinx Vitis AI 3.5**: Overlays pre-synthesized Deep Learning Processing Unit (**DPU**) IP cores onto the FPGA fabric, controlled via a standard C++/Python runtime.
- **FINN & Brevitas (AMD Research)**: Synthesizes bespoke **spatial streaming dataflow architectures** where quantized neural layers map directly into discrete hardware pipelines of Look-Up Tables (LUTs) and DSP slices.

```mermaid

    end
```

## 2. Core Architectural Mechanics: DPU vs. Dataflow Streaming

### Paradigm A: Coarse-Grained DPU (Vitis AI)
The DPU is an instruction-driven hardware accelerator instantiated on the FPGA programmable logic (PL). It fetches instructions (matrix multiplication, convolution, max pooling) generated by the Vitis AI compiler.
- **Advantage**: Changing model weights does not require re-synthesizing the FPGA bitstream in Vivado (compilation takes minutes, not hours).
- **Precision**: Highly optimized for **INT8** Post-Training Quantization (PTQ).

### Paradigm B: Spatial Streaming Dataflow (FINN)
FINN maps each neural network layer to a physically dedicated hardware pipeline stage connected by AXI-stream FIFOs.
- Layers communicate directly through hardware FIFOs without writing intermediate activations back to off-chip DDR RAM.
- **Ultra-low Precision**: Quantizes weights to **1-bit (Binarized Neural Networks)** or **2-bit/4-bit**, embedding weight matrices directly into the truth tables of 6-input FPGA LUTs (LUT-Net).
- **Latency**: Achieves inference latency under **$100\text{ microseconds}$** for high-rate visual inspection.

## 4. Engineering Implementation & Workflow

### A. Quantization with Vitis AI PyTorch Quantizer
```python
import torch
from pytorch_nndct.apis import torch_quantizer

model = MyVisionModel().eval()
dummy_input = torch.randn(1, 3, 224, 224)

# Instantiate quantizer in calibration mode
quantizer = torch_quantizer('calib', model, (dummy_input,), device=torch.device("cuda"))
quant_model = quantizer.quant_model

# Run calibration with 100 representative forward passes
with torch.no_grad():
    for img in calibration_dataloader:
        quant_model(img)

# Export quantized model for Vitis AI Compiler
quantizer.export_xmodel(output_dir="compiled_fpga_models")
```
